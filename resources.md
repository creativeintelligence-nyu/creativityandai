## Course technology requirements

You will need access to the following tools to participate in this course.

- Webcam
- Microphone
- Headphones (or quiet environment where you can engage verbally)
- Stable internet connection (cellular data may be problematic)
- Computer access (we recommend against using a mobile device). Users can access public Mac and PC computers throughout the Libraries. NYU students, faculty, and staff can also borrow wifi-enabled laptops. [Visit this link to learn more](https://library.nyu.edu/services/computing/on-campus/#:~:text=Users%20can%20access%20public%20Mac,Services%20page%20for%20more%20details.).

Please let me know if access to minimum course technology is a concern and I will help you find a solution.
